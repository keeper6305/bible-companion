# 바이블 컴패니언 · 말씀·배경·구절·인물 묵상

상황별 말씀, 성경 시대·문화 배경, 구절 탐색, 원어(히브리어·헬라어) 탐구, 나와 닮은 성경 인물, 개인 묵상 노트를 한 화면에서 보는 웹앱(PWA)입니다. 정통 개신교·복음주의 주석에서 합의된 해석만 담고 출처를 표기합니다.

- 앱: https://keeper6305.github.io/bible-companion/
- 설치: 휴대폰 브라우저에서 위 주소를 연 뒤 「홈 화면에 추가」 — 오프라인에서도 열립니다.
- 묵상 노트는 서버가 아니라 그 기기의 브라우저 저장소에만 남습니다.

## 수록 내용 (v2)

| 탭 | 내용 |
| --- | --- |
| 말씀 | 상황별 대화형 말씀 16편 — 공감 → 말씀 → 시대 배경 → 신학적 뜻 → 적용 질문 |
| 성경 | 구약 39권·신약 27권 **책 → 장 → 핵심 구절** 탐색. 40개 책 74개 핵심 구절에 본문 요지 · 시대·문화 배경 · 전체 맥락의 핵심 · 참고 근거 |
| 배경 | 시대·문화 배경 25편 (고대 근동 ~ 1세기 유대·로마) |
| 원어 | 히브리어·헬라어 26개 단어 |
| 인물 | 성경 인물 **21명** — 시대별 정리, 7단 구성(상황 · 시대 배경 · 하나님의 일하심 · 고난과 순종 타임라인 · 구원사적 의미 · 핵심 본문 · 적용 질문) |
| 노트 | 북마크·묵상 노트, JSON 백업/복원 |

## 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 앱 셸 (모든 경로는 상대경로 `./`) |
| `app.js` · `styles.css` | 화면과 라우팅 |
| `data/s1~s4.js` | 상황별 말씀 16편 |
| `data/b1~b2.js` | 시대·문화 배경 25편 |
| `data/words.js` | 원어 26개 |
| `data/c1~c3.js` | 인물 21명 |
| `data/books.js` · `data/verses.js` | 66권 목록 · 핵심 구절 74곳 |
| `data/daily.js` | 오늘의 한 구절 21개 (날짜 순환) |
| `sw.js` | 서비스 워커. HTML·데이터·앱 코드는 network-first(배포 즉시 반영), 아이콘은 cache-first |
| `qa.html` | 360/390/430 폭 자동 검증 하네스. `qa.html#shot?w=360&p=per` 로 화면 캡처 |

`sw.js`의 `CACHE_VERSION`은 배포 빌드가 내용 해시로 자동 갱신하므로 손으로 고치지 않아도 됩니다.

## 콘텐츠 원칙

1. 본문 우선 — 성경 66권 문맥을 1차 기준, 장르별 읽기 원칙을 따릅니다.
2. 검증된 자료만 — IVP 성경배경주석, NICOT·NICNT·BECNT·WBC, 피와 스튜어트 『성경을 어떻게 읽을 것인가』, 칼빈·매튜 헨리 주석, BDB·HALOT·BDAG, 요세푸스·미쉬나 등.
3. 개인 블로그·출처 불명 자료 배제.
4. 갈리는 지점은 ‘해석 주의’로 표시하고 단정하지 않습니다.
5. 저작권 — 개역개정 등 번역본은 장 전체를 복제하지 않고 핵심 1절 이내 발췌와 정확한 장·절 참조로만 사용합니다.
6. 모든 카드에 참고 근거를 표기합니다.
